# Part 1: 制单全流程 (15 分钟)

## TC-01. 单据建立

1. 左菜单 **委托运输 (ACC) → 制单中心 → 快件订单**
2. 点右上角 **+ 新增**
3. 弹窗填:
   - 客户: 选 **SELLER-DEMO**
   - 渠道产品: 选 **UPS Ground (US 国内)** (UPS-GROUND-US)
   - 收件人: `Test User`
   - 国家/邮编: `US / 33101` (FL Miami)
   - 重量: `1.5 kg`, 件数: `1`
4. 点 **提交**

**预期**:
- ✅ 返回订单列表, 看到新行 `客户单号 自动生成` 状态 `DRAFT`
- ✅ 列表"运费"列显示 **12.47 USD** ⭐ (R-12 SELLER-DEMO 9 折: 13.85 × 0.9)
- ✅ 列表"成本"列显示 **13.85 USD** (渠道商真价)

> ⚠️ 利润 = 12.47 - 13.85 = **-1.38 USD (亏损)** — 因为 R-12 SELLER-DEMO 是 9 折优惠模型。
> 用 DOC-DEMO 客户(没设 R-12)结果会是 AR = AP = 13.85, 利润 0。

## TC-02. R-1 同单去重

1. 同 TC-01 流程, 但客户单号填**跟上一单一样**的 (例如复制刚才系统生成的号)
2. 点 **提交**

**预期**: 
- ✅ 弹窗 "客户 + 单号已存在, 是否合并 / 覆盖 / 取消"

## TC-03. R-2 xlsx 批量导单

1. 在 **快件订单** tab, 右上角找 **📥 xlsx 批量导单** 蓝色按钮
2. 点开弹窗:
   - 必须先选 **客户** (例: TEST-US-001)
   - 点 **📥 下载模板** ⭐ — 应直接下 `批量导单模板.xlsx` (24 列中文表头 + 1 行示例)
3. 自己改模板填 2-3 行测试数据, 保存
4. 拖拽 xlsx 进弹窗 → 点 **预览** → 看见预览表 → 点 **提交导入**

**预期**:
- ✅ 模板真下载 (xlsx 文件不是 HTML)
- ✅ 预览看见行数 / 失败行有红色 + 错误说明
- ✅ 提交后 toast 显示 "导入完成: 成功 N / 失败 M"
- ✅ 订单列表立刻有新单

## TC-04. R-13 费用类目权限

1. 左菜单 **核算中心 → 费用类目**
2. 看到 15 个类目 (Ground/Fuel/Surcharge/Insurance/Battery/...)
3. 点 **+ 新增** → 填测试 code/name → 提交
4. 选刚加的行 → 点 **删除** → 确认

**预期 (admin 角色)**:
- ✅ 新建/删除均 HTTP 200 — admin 有 `finance.charge_item.write` 权限

# Part 3: 应收/补收 (10 分钟)

## TC-06. R-9 应收聚合列

1. 左菜单 **核算中心 → 应收运费**
2. 顶部 / 任一行展开看 charges 列
3. 注意 3 个新列 (R-9): **来源 / 补收 + / 回退 -**

**预期**:
- ✅ "来源" 列显示 emoji + 中文 (🤖系统预估 / 📥批量导入 / 🔁补收差值) (R-11)
- ✅ "补收 +" / "回退 -" 列存在 (大部分为 0)

## TC-07. R-8 单笔补收

1. **核算中心 → 应收运费** 列表中选一行 (例如 charge id `b8322416`)
2. 点行的 **补收** 按钮 (或弹窗操作)
3. 弹窗填:
   - 模式: **DELTA** (默认)
   - 新金额: 比原金额大 1.50
   - 备注: `验收测试`
4. 提交

**预期**:
- ✅ Toast 显示 "补收成功"
- ✅ **该 charge 行**的"补收 +"列变成 +1.50
- ✅ 新生成一行 ADJUST 类型 charge, "来源"列显示 🔁

> 验证完后**记得撤回**: 把同一行再补收 -1.50, 或者前端有"撤销补收"按钮

## TC-08. R-7 xlsx 批量补收

1. **核算中心 → 应收运费** tab
2. 顶部 **📤 xlsx 批量补收** 按钮
3. 点开弹窗 → **📥 下载模板** (4 列: 运单号/新金额/新重量/备注)
4. 填测试数据 → 上传 → 选 DELTA 模式

**预期**:
- ✅ Toast: "补收完成: 处理 N / 跳过 M"
