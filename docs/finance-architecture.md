# 财务模块系统架构

## 目标

财务模块要把当前痛点里的“人工判断、月底补救、Excel 对账”前移成规则化能力：出货前可预估，应收可解释，应付可导入，对账只处理异常，利润与提成自动汇总。

## 痛点覆盖

| 痛点 | 系统能力 |
| --- | --- |
| 敏感品、尺寸、偏远、低消、燃油、保险漏收 | 规则版本 + 费率引擎 + 费用行证据 |
| 附加费叠加/取大不灵活 | `combination_group` + `combination_strategy` + `scope` |
| 合并报关重复收费 | `customs_groups` 只生成一笔费用，支持均摊或挂主票 |
| 渠道账单模板复杂 | 账单导入模板、原始行、标准字段映射、异常队列 |
| 主/子单和补收匹配不稳 | `shipments` + `cartons.tracking_no` + 多键置信度匹配 |
| 客户账单人工生成 | 账单模板、版本、门户下载、自动邮件接口预留 |
| 卡派转快递比价看不到附加费 | `delivery_quote_options` 汇总基础运费与风险附加费 |
| LTL/卡派代理无法预估 | 快递与 LTL 双轨渠道价卡 |
| 保险手工录单与漏入账 | `insurance_policies` + API 事件 + 自动生成应付费用 |
| 成本月底逐票核对 | 前置 `channel_cost_policies` 生成预期成本，导入实际账单后自动比对 |

## 逻辑架构

1. 运营后台：客户、合同、渠道、价卡、规则、账单、异常处理。
2. 财务 API：费率计算、账单导入、应收应付、对账、利润、提成。
3. 规则引擎：按渠道、合同、客户、时间版本加载规则。
4. 对账引擎：模板映射、费用科目化、多键匹配、差异分类。
5. 账本层：将已锁定费用、收款、成本和调整过账为不可变复式分录。
6. 集成适配器：承运商账单、保险 API、汇率、轨迹、邮件。
7. 数据库：PostgreSQL + RLS，保存主数据、交易数据、规则版本和审计。
8. 异步任务：账单解析、批量对账、邮件发送、保险回调，使用幂等键和任务审计。
9. 授权与审批：角色、权限、对象范围、财务调整审批和绕 SOP 审批。

## 财务域边界

- 计费规则：价卡、重量/方数/磅/件、低消、分抛、燃油、附加费、偏远、保险、报关。
- 应收：试算、锁定、账单生成、客户对账、收款核销。
- 应付：预期成本、渠道账单导入、保险保费、BL/柜级成本分摊。
- 对账：系统费用 vs 渠道实收，按重量差、单价差、附加费差、漏收/多收分类。
- 账本：费用锁定后生成正式分录，历史不可改，差异通过冲销或调整分录处理。
- 利润：应收、销售成本、预估成本、实际成本、毛利、差异告警。
- 提成：按方案配置来源口径，月度汇总，人工复核后确认。
- 权限：对账、改价、冲销、过账、绕 SOP 拆成独立权限，并保留审批记录。

## 核心数据流

1. 客户下单或仓库量尺后，系统计算箱级计费重。
2. 费率引擎加载合同价卡、渠道价卡、规则版本，生成 AR/AP 费用草稿。
3. 操作选择快递或卡派时，系统生成多家代理报价与超长/超重风险。
4. 投保时推送保险 API，保单返回后写入保险表并生成应付保费。
5. 财务导入渠道账单，系统保留原始行并映射为标准字段。
6. 对账引擎按主单、子单、客户参考号、日期、金额、Zip/Zone 计算匹配置信度。
7. 匹配成功自动生成实际成本，差异进入异常队列。
8. 应收和应付完成后刷新利润，进入结案和提成计算。

## 技术架构

- 前端：Vue 3 + Vite，先做运营后台，后续扩展客户门户。
- API：TypeScript + Fastify，按财务域分模块；后续可迁移或拆成 Spring Boot 域服务。
- 数据库：PostgreSQL + RLS，迁移脚本在 `db/migrations`。
- 缓存与队列：Redis，承担批量导入、对账任务状态、幂等锁和异步通知。
- 对象存储：后续保存原始账单、客户账单 PDF、保险保单。
- 集成：保险公司 API、汇率服务、承运商账单/API、邮件/企业微信。

## MVP 优先级

P0:
- 多租户、客户、合同、渠道、价卡、费用项字典、数据库 RLS。
- 规则版本、附加费叠加/取大、箱级低消、分抛、燃油月表。
- 运单、箱、申报、费用行。
- 渠道账单导入、标准字段映射、对账结果。
- 客户账单、收款、不可变账本、利润基础视图。
- 批量任务、导入文件指纹、幂等键。
- 角色权限、财务调整审批、绕 SOP 审批。

P1:
- LTL/快递比价、超重/超长风险弹窗。
- 保险 API 推单、保单回传、保费自动入账。
- 合并报关费用均摊。
- BL/柜级成本批量分摊。

P2:
- 客户门户下载账单、自动邮件。
- 销售提成月结。
- OCR/大模型解析原始账单。
- 多币种结汇损益和账龄预警。

## 数据库说明

`001_init.sql` 已覆盖财务模块主要实体。关键表：

- `charge_rules`: 附加费、偏远、保险、报关等规则。
- `charges`: 应收/应付费用行，保存规则快照与证据。
- `carrier_bill_imports` / `carrier_bill_lines`: 渠道账单导入和原始行追溯。
- `reconciliation_results`: 对账匹配、差异分类和处理状态。
- `delivery_quote_options`: 快递/LTL 比价与风险确认。
- `insurance_policies`: 保险 API 回传和保单关联。
- `customs_groups`: 合并报关只收一次。
- `cost_allocation_batches`: BL/柜级成本分摊。
- `ledger_accounts` / `ledger_transactions` / `ledger_entries`: 正式不可变复式账本。
- `background_jobs` / `idempotency_keys`: 批量导入、对账、保险回调等异步任务底座。
- `roles` / `permissions` / `user_roles` / `role_permissions`: API 授权模型。
- `approval_policies` / `approval_requests` / `approval_decisions`: 财务调整与绕 SOP 审批。
