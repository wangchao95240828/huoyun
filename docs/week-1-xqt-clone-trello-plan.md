# 本周新智慧复刻分工看板

周期：2026-05-06 周三 至 2026-05-08 周五

## 项目口径

我们不是把新智慧作为长期外部系统接入，而是把新智慧作为业务样本，倒推出页面、字段、筛选、状态、金额口径和流程，然后在我们的新系统里复刻并优化。

本周只做只读核心能力复刻：页面能看、数据能查、字段口径能对照。新增、编辑、审核、核销、开票、导入、导出等写操作放到下周拆解。

## 本周验收目标

| 验收项 | 标准 |
| --- | --- |
| 财务核心页面 | 新系统内有财务流水、客户账单、供应商账单、客户流水、供应商流水、运单审计页面 |
| 数据来源 | 使用我们自己的数据库和 API，不依赖新智慧线上接口作为运行时数据源 |
| 字段复刻 | P0 页面搜索条件、表格字段、状态枚举完成 80% 以上对齐 |

| 对照验证 | 每个 P0 页面至少完成 3 组人工对照用例 |
| 输出物 | 表结构、API、页面、字段口径、问题清单均有文档或代码落地 |

## 暂不做

| 功能 | 原因 |
| --- | --- |
| 新增/编辑账单 | 涉及写操作和业务状态流转，本周先只读复刻 |
| 审核/退回/取消 | 需要完整权限、审批日志、状态机设计 |
| 核销/付款 | 涉及资金流水和账务一致性，需要单独方案 |
| 开票/冲账 | 涉及发票、税务、冲账金额口径，下周拆 |
| 导入/导出 | 容易触发数据动作，先不碰新智慧写接口 |

## 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 新智慧字段含义不明确 | 复刻口径可能偏差 | 用页面对照和业务确认，未确认字段标 `unknown` |
| 金额字段多且相似 | 应收、应付、利润、冲账容易混 | 金额字段先分组展示，不急着合并 |
| 下拉选项量很大 | 用户、供应商、服务下拉难一次性复刻 | 本周先用字典/种子数据，后续做真实字典管理 |
| 写操作未拆解 | 本周无法完整替代新智慧 | 明确本周只读复刻，下周做状态流转 |

## 本周完成定义

本周结束时，我们应该能在新系统里打开财务模块，看到与新智慧核心页面对应的列表和筛选，且数据来自我们自己的库和 API。新智慧只用于对照验证，不作为运行时依赖。
